# SuperClaude Guide

Provides an accessible, practical manual explaining all SuperClaude slash commands, specialized AI agents, and workflow skills with real-world scenarios.

## Usage

```text
/claude-super-guide
/super-claude:claude-super-guide
```

## What This Command Does

1. Explains the core architecture (Commands, Agents, Skills).
2. Presents 4 real-world engineering scenarios (Feature Development, Bug Triage, Tech Research, Code Learning).
3. Provides a full command lookup table with plain-language explanations and input examples.
4. Explains how to leverage 21 specialized agents effectively.
5. Answers common questions on skill updates and workflow combinations.

## Quick Trigger

Type `/super-claude:recommend` to get personalized suggestions for your current repository state.
