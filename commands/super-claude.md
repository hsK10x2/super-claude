# SuperClaude Command Dispatcher

🚀 **SuperClaude Framework** - Main command dispatcher

## Usage

All SuperClaude commands use the `/super-claude:` prefix:

```
/super-claude:command [args...]
```

## Available Commands

### 🔍 Research & Analysis
```
/super-claude:research [query]         - Deep web research with parallel search
/super-claude:analyze [path]           - Comprehensive code quality, security & performance analysis
/super-claude:spec-panel               - Multi-perspective specification review
/super-claude:business-panel           - Business impact and product value analysis
```

### 🧠 Planning & Design
```
/super-claude:brainstorm [topic]       - Interactive requirements and architecture brainstorming
/super-claude:design [feature]         - System architecture and API design
/super-claude:estimate [task]          - Development effort and complexity estimation
```

### ⚡ Implementation & Quality
```
/super-claude:implement [spec]         - Structured step-by-step implementation workflow
/super-claude:test [target]            - Test execution with coverage and validation
/super-claude:troubleshoot [issue]     - Systematic debugging and root cause analysis
/super-claude:cleanup                  - Dead code removal and project cleanup
/super-claude:improve                  - Target code refactoring and improvement
```

### 📦 Repository & Task Management
```
/super-claude:index-repo               - Index repository for token and context optimization
/super-claude:task [action]            - Task tracking and milestone management
/super-claude:workflow [name]          - Multi-phase structured engineering workflows
```

### 🤖 Specialist AI Agents
```
/super-claude:agent [type]             - Launch specialized AI agents
```
Available agents:
- `@system-architect` : High-level architecture and system design
- `@deep-research-agent` : Comprehensive web research and synthesis
- `@pm-agent` : Product management and requirements analysis
- `@security-engineer` : Security audit and vulnerability assessment
- `@performance-engineer` : Bottleneck profiling and optimization
- `@root-cause-analyst` : Deep root-cause debugging
- `@quality-engineer` : Test strategy and QA verification
- `@refactoring-expert` : Clean code and technical debt reduction

### 💡 Recommendations & Help
```
/super-claude:recommend                - Get command recommendations based on project state
/super-claude                          - Show this help dashboard
```
